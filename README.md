# Joes Unblocked

A GitHub Pages-ready game library with a searchable dashboard and built-in game player.

## Add your own HTML game

1. Add the game file to the `games` folder.
2. Add its name, file path, and description to `games.js`.
3. Upload both files to your repository. The game card is added automatically.

See [games/README.md](games/README.md) for the exact one-line example.

## Publish with GitHub Pages

In your GitHub repository, go to **Settings → Pages**, choose **Deploy from a branch**, and select `main` and `/ (root)`. No build step is required.
