# Add your own games

1. Put a complete game HTML file in this folder, for example `my-game.html`.
2. Open `../games.js` and add an entry inside `GAMES`:

```js
{ name: 'My Game', file: 'games/my-game.html', description: 'A short description' },
```

3. Save and upload both files to GitHub. The new card appears automatically.

Use a file name with lowercase letters, numbers, and hyphens for the smoothest GitHub Pages links.
